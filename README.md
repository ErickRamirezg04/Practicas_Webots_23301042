## 🚀 Cómo descargar la carpeta para visualizar los archivos

Para poder explorar los mundos y tener acceso a los controladores de este proyecto, sigue estos sencillos pasos:

### 1. Descargar el repositorio
Haz clic en el botón verde **`Code`** (arriba a la derecha en GitHub) y selecciona **`Download ZIP`**. Descomprime el archivo `.zip` en tu computadora.
### 2. Acceso
Con el acceso completo a la carpeta, desde la aplicación de Webots se accede a los diferentes mundos y sus controladores
